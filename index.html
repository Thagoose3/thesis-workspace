Firebase & Google Cloud Sync

เชื่อมต่อ Firebase เพื่อล็อกอิน Google และซิงก์ข้อมูลข้ามเครื่อง

🚀 วิธีนำ Firebase Config มาใส่ (ทำครั้งเดียว):

  1. เปิด Firebase Console แล้วสร้าง Project
  2. ไปที่ Authentication ➔ เปิดใช้งาน Google Sign-In Provider
  3. ไปที่ Firestore Database ➔ กดสร้าง Database (เลือก Test mode)
  4. ไปที่ Project Settings ➔ เลื่อนลงมาที่ Web Apps ➔ คัดลอกโค้ด firebaseConfig มาวางในช่องด้านล่าง
